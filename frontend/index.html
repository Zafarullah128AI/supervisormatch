Smart matching

Full approval cycle

Student request → teacher accepts → admin approves. Every step notifies everyone involved, and nothing gets lost in WhatsApp chats.

🏆

Supervisor rankings

A live leaderboard ranked by student ratings, approved assignments and total matches — so the best supervisors rise to the top.

💬

AI assistant + idea check

Chat with the built-in assistant about your title and description. Powered by Gemini AI when a key is set (otherwise it answers with built-in rules). It checks idea quality, warns about random-letter input, and tells you if a similar project was done before.

📊

Measured, not guessed

Evaluated on 10 labeled test ideas: full pipeline Hit@5 0.8, MRR 0.57, NDCG@5 0.628 — better than TF-IDF alone on every metric. With BERT semantic matching, Hit@5 rises to 0.9.
